# 50 original grammar practice sets — 14 November 2026

## Scope and purpose
- 50 genuinely different grammar practice topics: A1 14, A2 14, B1 12, B2 10.
- Each page contains a topic-specific rule, a distinct common mistake, four original worked examples with English translations, four individual gap-fill questions with concealed answer explanations, a revision prompt and direct links to related grammar and the free A1 chapter.
- 200 model sentences + 200 answer-explained tasks (all independently authored, not copied from exam papers).
- The static practice hub groups lessons by CEFR level and links to every guide; Resources links to the hub and representative lessons.
- Source canonical URLs include .html and are rewritten to clean URLs during the public-artifact deployment; sitemap and related links follow the existing deployment transformation.
- No private course text, exam portal internals, payment data, protected audio, or paid resources were added.
- No new tracking, scripts, JavaScript quizzes, third-party runtime or external images. HTML <details> makes explanations accessible without JS. Brand styling uses forest-green and navy; no orange.

## Editorial review
- Automated checks are not a substitute for native German teaching review and English copyediting; review German morphology and nuance before promoting pages heavily.
- No official Goethe scoring, exam questions, government requirements, fee or ranking claims.
- Drafts were generated as original independent exercises with AI assistance for owner and editorial review. No claim is made that a human teacher reviewed each exercise.
- SEO intent: distinct practice searches for pre-existing grammar lessons. Do not treat count or indexing requests as a promise of Google inclusion.

## QA gates
- scripts/seo-practice.test.mjs validates all 50 datasets, output pages, hub links, canonical, sitemap and allowlist.
- npm test, npm run check:generated, artifact leak and deployment checks should all pass before merge.
