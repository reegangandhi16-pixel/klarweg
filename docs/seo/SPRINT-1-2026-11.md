## 2. Google Search Console: your checklist

Nothing below has been done. Search Console is **not verified** until you complete step 4.

1. Open <https://search.google.com/search-console>, signed in with the Google account that should own the data.
2. **Add property** → choose **Domain** (the left box, not "URL prefix") → type exactly `klarweg.in` (no `https://`, no `www`). A Domain property covers http, https, www and every subdomain.
3. Google shows a TXT record value beginning `google-site-verification=`. **Copy that exact value.** Do not type it by hand and do not use any example value.
4. In Cloudflare: **dash.cloudflare.com** → select **klarweg.in** → **DNS** → **Records** → **Add record**:
   - Type: **TXT**
   - Name: **@** (Cloudflare displays it as `klarweg.in`)
   - Content: paste the value from step 3
   - TTL: Auto → **Save**
   Do not edit or delete any existing records. If another TXT record exists (e.g. for email), leave it; multiple TXT records are fine.
5. Back in Search Console → **Verify**. DNS changes can take from minutes to a few hours; if it fails, wait and press Verify again. **Keep the TXT record permanently**: deleting it un-verifies the property.
6. **Sitemaps** (left menu) → enter `https://klarweg.in/sitemap.xml` → **Submit**. (The 3 new grammar pages appear in it only after this branch is deployed.)
7. After the deploy: **URL Inspection** → paste each new URL → **Test live URL** → **Request indexing**:
   `https://klarweg.in/grammar/der-die-das.html`, `…/grammar/akkusativ.html`, `…/grammar/dativ.html`.

| URL | Title | Primary intent |
|---|---|---|
| `https://klarweg.in/grammar/der-die-das.html` | Der, Die, Das: German Articles and Noun Gender Explained | der die das rules, German articles, noun gender |
| `https://klarweg.in/grammar/akkusativ.html` | Akkusativ in German: The Accusative Case Explained | Akkusativ, accusative case German |
| `https://klarweg.in/grammar/dativ.html` | Dativ in German: The Dative Case Explained | Dativ, dative case German, Akkusativ vs Dativ |

**Cannibalisation check:** the overlapping topics exist only as paid chapters (A1·10, A1·12, A1·36), which are `noindex`, and as one-line rows on `german-grammar.html`, which targets the syllabus and list query. No indexable page targeted these queries before. Akkusativ vs Dativ is handled inside the Dativ guide (§ "Akkusativ or Dativ?") and linked from the Akkusativ guide, not as a fourth page.

**Outlines**
- **Der, die, das:** 30-second summary · what articles are (grammatical vs natural gender) · Hindi vs German gender table (किताब/das Buch, मेज़/der Tisch, सूरज/die Sonne…) · article table (der/ein/kein/mein) · endings that predict gender (feminine, masculine, neuter, with exceptions) · compound nouns · same word, different gender · how to learn articles · 5 common mistakes · 10 + 3 exercises with answers · course link (A1 Ch. 10).
- **Akkusativ:** summary + colour key · what it does (Wen? Was?) · Nom vs Akk table (only masculine changes) · n-Deklination note · pronoun table · everyday Akk verbs, *es gibt*, not after *sein* · durch/ohne/gegen/für/um · Akk vs Dativ with two-way prepositions · why word order can flip (*Den Hund sieht der Mann*) · the Hindi को trap · 6 mistakes · 10 exercises · course link (A1 Ch. 12, 32).
- **Dativ:** summary + colour key · what it does (Wem?) · three-case article table · pronoun table (Nom/Akk/Dat) · two-object verbs and object order · Dativ-only verbs (helfen, gefallen…) · where Hindi helps (मुझे ठंड लग रही है = Mir ist kalt) · aus/bei/mit/nach/seit/von/zu, contractions, nach/zu Hause, *seit* ≈ से · Akkusativ or Dativ (Wo?/Wohin? table + case summary) · 7 mistakes · 12 exercises · course link (A1 Ch. 36–41, A2 Ch. 21).

**Paid-content boundary:** the guides were written without opening the paid chapters' data files. They link only to free Chapter 1 and public pages, which `scripts/grammar-guides.test.mjs` enforces.
