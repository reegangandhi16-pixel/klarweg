Choose a learning route for your week

With irregular hours, start with short self-paced sessions and add speaking when you can book it. With a dependable weekly slot, compare available live classes in IST. For an exam, work back from the date you need the result and set a skill checkpoint before booking.

Run a first-week starting check

Say your name, city and reason for learning. Then ask one simple question. If that is already easy, explain what you did last weekend instead and note where you get stuck.

Check one possible answer

Ich heiße Ravi. Ich wohne in Jaipur. Ich lerne Deutsch für meine Arbeit. Warum lernst du Deutsch?

Use the response to choose a level and one skill to practise next. A quick speaking sample helps you start, but it is only one part of placement.
