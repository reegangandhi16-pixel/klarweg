## Der, die, das (`/grammar/der-die-das.html`)

Gender patterns and their stated exceptions
- [ ] Usually feminine: -ung, -heit, -keit, -schaft, -ion, -tät, -ie, -ei, -in (female person), most nouns in -e.
- [ ] -e exceptions given: der Name, der Junge, der Käse; das Auge, das Ende.
- [ ] Usually masculine: days, months, seasons; directions and most weather words (der Norden, der Regen, der Schnee, der Wind); male people and many jobs; -ling, -ismus.
- [ ] Usually neuter: -chen, -lein ("always"), -ment, -um; verbs used as nouns (das Essen, das Lernen).
- [ ] -er "often masculine": exceptions das Zimmer, das Fenster, die Mutter, die Butter.
- [ ] Compound nouns take the gender of the last word (die Haustür, der Kindergarten, der Bahnhof).
- [ ] Same word, different gender: der/die See, die/das Steuer, der/die Band; meanings correct.
- [ ] Countries: most take no article (Ich komme aus Indien); exceptions die Schweiz, die Türkei, der Iran, die USA (plural).
- [ ] All plurals take die; "die Mädchen" is plural only.
- [ ] Article table der/ein/kein/mein across m/f/n/plural (Nominativ).

## Akkusativ (`/grammar/akkusativ.html`)

- [ ] Only masculine changes in the Akkusativ: der→den, ein→einen, kein→keinen; f/n/pl unchanged.
- [ ] n-Deklination examples: Student, Junge, Kollege, Herr, Name (den Studenten, den Herrn, den Namen).
- [ ] Pronouns Nom→Akk: ich/mich, du/dich, er/ihn, sie/sie, es/es, wir/uns, ihr/euch, sie/Sie.
- [ ] *es gibt* + Akkusativ (Hier gibt es einen Supermarkt).
- [ ] *sein*, *werden*, *heißen* take Nominativ, not Akkusativ (Das ist ein Hund).
- [ ] Akkusativ prepositions: durch, für, gegen, ohne, um.
- [ ] "Den Hund sieht der Mann" means the man sees the dog; the explanation of word order.
- [ ] Two-way prepositions: Wohin? → Akk, Wo? → Dativ (cross-reference to the Dativ guide).

**HI**
- [ ] मैंने राम को देखा, राम को किताब दो: को can mark either a direct object (Akk) or recipient (Dat), so it does not map 1:1 onto Akkusativ.
- [ ] मैं चाय पीता हूँ → Ich trinke Tee: no को in Hindi, but Tee is still an Akkusativ object.

## Dativ (`/grammar/dativ.html`)

- [ ] Three-case article table (Nom/Akk/Dat): dem/der/dem/den; einem/einer/einem.
- [ ] Dativ plural adds -n to the noun except nouns already ending in -n or -s (den Kindern, den Autos).
- [ ] Pronouns Dat: mir, dir, ihm, ihr, ihm, uns, euch, ihnen/Ihnen.
- [ ] Object order: two nouns → Dativ first (Ich gebe dem Mann das Buch); Akk is a pronoun → pronoun first (Ich gebe es dem Mann); both pronouns → Akk first (Ich gebe es ihm).
- [ ] Dativ-only verbs listed (helfen, danken, gefallen, gehören, antworten, passen, schmecken); gefallen takes the thing as subject (Die Jacke gefällt mir).
- [ ] "Passt dir Montag?" as natural colloquial German.
- [ ] Dativ prepositions: aus, bei, mit, nach, seit, von, zu.
- [ ] Contractions: zum, zur, beim, vom.
- [ ] nach Hause (direction) vs zu Hause (location).
- [ ] *seit* + present tense (Ich lerne seit einem Jahr Deutsch) vs *für ein Jahr* for a planned period (Ich gehe für ein Jahr nach Berlin).
- [ ] Nine two-way prepositions: an, auf, hinter, in, neben, über, unter, vor, zwischen.
- [ ] Mistake corrected earlier: "Ich gehe mit meiner Mutter einkaufen" (not *meine*).

**HI**
- [ ] मुझे ठंड लग रही है ≈ Mir ist kalt; मुझे यह जैकेट पसंद है ≈ Die Jacke gefällt mir; मुझे फ़िल्म पसंद है.
- [ ] उसे किताब दो ≈ Gib ihm das Buch; मैंने उसको देखा → Ich habe ihn gesehen (Akk, not Dat).
- [ ] मैं एक साल से जर्मन सीख रहा हूँ ≈ seit + present (से ≈ seit).
