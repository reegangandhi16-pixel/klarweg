# Example-sentence corrections — visual vocabulary coverage 2

Date: 2026-11-19 · Branch: `feat/visual-vocab-coverage-2` · **Not merged, not deployed.**

## Why
Every card's German example now sits directly under its visual and carries the
highlighted word, so a wrong or unnatural example would be taught twice. The owner asked to
“correct weak or grammatically incorrect example sentences, but do not silently change
educational content without documenting it.” This file is that documentation.

## How
1. `scripts/vocab-images/example-audit.mjs`: a strict text model read all **9,230** examples
   (with headword, meaning, level and chapter) and **reported** 376 problems (report-only, $3.84).
2. Every finding was reviewed by hand. Decisions: **316 applied**, **41 rejected**
   (the sentence was fine, or the fix would have changed the chapter’s teaching point),
   **19 left for the owner** (headword or chapter-design questions, below).
   Where the model’s replacement was itself weak, the reviewer wrote the sentence
   (marked *reviewer wording*). Four sentences were chosen to match an existing image.
3. `scripts/vocab-images/apply-example-fixes.mjs` changed only `ex` / `exEn` of the listed
   cards and verified that nothing else in any chapter changed. Headwords, meanings, Hindi,
   audio, plurals and grammar colours are untouched (vocab-card audio plays the headword only).
4. The word-popup dictionary (`chapter/global-lexicon.js`) is a separate source with its own
   examples and was **not** changed. `global-lexicon-public.js` was regenerated only because
   the free chapters’ text changed (4 generic words added: klarheit, putzen, revolution, sorgen für).

## Owner decisions — resolved 2026-11-20 (19)
Owner rule: keep each chapter's teaching goal; fix only verified errors; German must match English, Hindi and the card image.
References: Duden online (phrasieren, Roadmovie, erröten, Kunststück, Meisterschaft, kreisen/einkreisen), DWDS (no entry „rotschämen“; erröten, Beherrschung, Meisterschaft).

**B1·26 (Adjektivdeklination ohne Artikel).** The chapter's own story uses plurals and nothing in it frames examples as headlines, so singular count nouns without an article were genuine errors (learners would copy them). No article was added anywhere; every fix keeps a strong ending without an article. Singular was kept wherever German allows it: mass nouns, *als*, exclamation, *in* + dative.
