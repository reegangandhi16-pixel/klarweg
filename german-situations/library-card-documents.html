Check documents for a library card in German

Ask if you can register today and whether an ID is enough to get a card.

Try your response

Say or write what you would use in this situation, then compare the wording.

Show the German model and English meaning

Kann ich mich heute anmelden? Reicht mein Ausweis für den Bibliotheksausweis?

Can I register today? Is my ID enough for the library card?

Reicht asks whether the document is sufficient. The two Ausweis compounds identify different cards.

Try it with a change

You only have a passport. Ask if the library also needs proof of your address.
