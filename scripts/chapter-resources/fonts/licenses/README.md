chapter resource PDFs. They are unmodified static instances downloaded from
Google Fonts and are redistributed under the **SIL Open Font License 1.1**.
Each family's copyright notice and full licence text is in this folder.

| `NotoEmoji-400.ttf` | Noto Emoji | [notoemoji-OFL.txt](notoemoji-OFL.txt) |
